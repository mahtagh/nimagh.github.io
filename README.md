# Nima Ghorbanian, academic portfolio

A one-page static site. It needs no build step.

## Publish on GitHub Pages (about 5 minutes)

1. Sign in to GitHub and create a new **public** repository named `USERNAME.github.io`, replacing `USERNAME` with the GitHub username. The site will live at `https://USERNAME.github.io`.
2. Click **Add file → Upload files** and upload `index.html` and `cv.pdf`. Click **Commit changes**.
3. Go to **Settings → Pages**. Under "Build and deployment", choose **Deploy from a branch**, then select the `main` branch and the `/ (root)` folder. Click **Save**.
4. Wait a minute or two, then open `https://USERNAME.github.io`.

To change the CV, upload a new PDF with the same name, `cv.pdf`.

## Add Nima's photo

Upload a square headshot named `photo.jpg` (about 600 × 600 pixels) to the same repository. It appears automatically in the "About me" circle. Until then, the circle shows his initials.
